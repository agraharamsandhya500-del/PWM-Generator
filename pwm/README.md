# PWM Generator Using Verilog

## Project Description

This project implements a **Pulse Width Modulation (PWM) Generator** using Verilog HDL.

The PWM output is generated by comparing an 8-bit counter with an 8-bit duty-cycle input.

## Features

* 8-bit PWM resolution
* Adjustable duty cycle
* Synchronous counter operation
* Reset input
* Verilog HDL implementation
* Testbench for simulation

## Duty Cycle

| Duty Cycle Input | PWM Duty Cycle |
| ---------------: | -------------: |
|                0 |             0% |
|               64 |            25% |
|              128 |            50% |
|              192 |            75% |
|              255 |          ~100% |

## Files

* `pwm_generator.v` — PWM generator module
* `pwm_generator_tb.v` — Testbench
* `README.md` — Project documentation

## Working Principle

The counter continuously counts from 0 to 255.

The PWM output is HIGH when:

`counter < duty_cycle`

Otherwise, the PWM output is LOW.

## Simulation

The testbench verifies the PWM generator at:

* 25% duty cycle
* 50% duty cycle
* 75% duty cycle
* 100% duty cycle
